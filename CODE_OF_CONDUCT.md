# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and do not harass anyone.
Harassment, personal attacks and publishing others' private information are not tolerated.

## Enforcement

Report unacceptable behavior to the maintainer, [@bloogefest](https://github.com/bloogefest),
using the contact details on the maintainer's GitHub profile. Reports are handled confidentially. The maintainer may
remove comments, close issues or block participants who violate this code.
